## 这一套配色和描边就是基调本身

这是全库第一个被用户点名「长期复用」的方案。复用的是下面这套字处理，不是漏斗主体。

| 项 | 规定 |
|---|---|
| 背景 | 暗灰黑 #1A1A1C，极淡细网格，不抢标题 |
| 第一行（引题） | 纯白，不要渐变、不要金属反光条 |
| 第二行（主判断） | 高饱和柠檬黄 #FFDD00，接近纯黄，**绝对不许发橙发暗**，放到最大 |
| 强调字 | 朱红 #FF3B20，只给一两个字 |
| 描边 | 两层：紧贴字身一圈中等厚度纯黑，外面再加一圈很细的深灰 #3A3A3C |
| 外发光 | 只有强调字带一点很淡的红色外发光，其余字完全没有发光 |
| 立体厚度 | 纯黑，比较薄 |
| 字形 | 超粗中文综艺海报黑体，方正饱满、笔画极粗、字距极紧，整行略微倾斜 |

- 不复用：漏斗、灰方块、金黄卡片是这篇文章的隐喻，换文章要换主体；只有上面这张表跟着走。
- 对照组：A49（硬投影贴纸）、A50（硬黑描边无发光）用户说「也还行」，可作同一基调下的变体；R14 的白边在外、金线内收微光、银白为主三个方案已淘汰。
