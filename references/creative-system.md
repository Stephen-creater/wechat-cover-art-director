# 创意系统

## 模板探索优先

当任务目标是扩充模板库，不要先问“这个题材画什么”，先问“还有哪一种成熟封面语法尚未验证”。标题只是压力测试材料：短标题检验尺度与留白，中标题检验层级，长标题检验行数、字宽和中英文混排。

生成前把每个候选写成五元组：`版式骨架 / 明暗 / 媒介 / 主体机制 / 标题容量`。若它与任一正向或负向历史提示词在其中三项以上相同，视为重复，不生成。

双向去重：

- 正向去重：已通过的环轨、双环、桥、中央核心波场、红蓝杂志、纸浪、沙漏、双路径等，不再以换色或换标题形式占用发散名额。
- 负向去重：芯片剖面、普通控制台、服务器阵列、液态玻璃、折纸、抽屉、机械臂、缓存门户、数据峡谷、X-ray 引擎等，不做同构变体。
- 允许借用一个维度，例如 A08 的明亮编辑感；但主体、版式和材质至少两项必须进入新空间。

## 方向矩阵

为每批封面建立一个简短矩阵，确保真正发散：

| 轴 | 可选方向 |
|---|---|
| 背景 | 米白、浅灰、柔和蓝、杏橙、薄荷绿、天空渐变、彩色摄影环境、少量深色 |
| 版式 | 左文右图、居中标题、上下分区、对角线、主体穿插文字、满版摄影留字区 |
| 媒介 | 编辑摄影、产品级 3D、纸艺、超现实合成、字体设计、精炼图解、空间建筑 |
| 隐喻 | 容器、道路、接力、复印、影子、书页、流水线、抽屉、积木、闸门、回声、时间层 |

同一批方向不要在两个以上的轴上重复。若五张都能用同一句 prompt 描述，只是改了颜色，说明分流失败。

上表是通用启发，不是待办清单；已在 [template-space.md](template-space.md) 标记为通过或淘汰的组合不再重复。

## 如何吸睛但不花哨

- 放大一个有意义的主体，而不是增加十个小元素。
- 使用鲜明但有限的色块关系，而不是提高所有颜色饱和度。
- 制造清楚的尺度反差、前后关系或视觉悬念。
- 让标题与主体发生关系，例如穿插、遮挡、框定或沿路径排布，但不能损害可读性。
- 用摄影光线、纸张肌理、半透明材质或空间深度提高完成度。

## 如何避免普通

- 不使用“标题左边、通用面板右边”作为默认答案。
- 不使用抽象方块代表所有技术概念，除非方块的行为能准确说明机制。
- 不用无意义的发光线路、数据点和缓存条装饰。
- 不直接画产品名对应的图标；先找文章里的动作和因果。
- 每张封面都应能用一句具体话解释：画面里的主体为什么只能属于这篇文章。

## 配色原则

- 黑色不是默认底色。
- 一张图采用一个主背景色、一个主体色和一个强调色即可。
- 亮色封面也要有深色文字或阴影支撑层级。
- 推荐有审美稳定性的组合：米白+钴蓝+橙、浅蓝+深蓝+珊瑚、杏色+酒红+墨蓝、薄荷+深绿+暖黄、银灰+紫+橙。
- 避免荧光黄红大面积碰撞、彩虹渐变和所有元素同时发光。
