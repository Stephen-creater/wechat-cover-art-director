# 已确认失败模式

只用于排除，不得作为正向风格参考。逐轮淘汰记录见 [反馈历史档案](feedback/history.md)；具体反例图片与提示词见 [rejected-index.md](rejected-index.md)。

## 明确原因的失败（高置信，必须规避）

| 来源 | 用户原话或明确原因 | 禁止 |
|---|---|---|
| R01 黑底科技批次 | 全部淘汰、非常不满意：整批黑底、普通、元素奇怪、排版模板化 | 深色面板、缓存方块、普通左右 UI、同色系整批 |
| R1-OAI-03-v2 | 仅水平居中、整体偏下 | 居中标题不在画布几何中心 |
| A32 排版 | 在“做业务的”后换行，第三行拥挤 | 拆开核心语义短语 |
| R12 E03 | 字压在下面，配图很奇怪 | 压低标题 + 红色增长线 + 金色撕纸裂口的组合 |
| R12 E05 | 看着奇怪，左右两边是什么看不懂 | 缩略图下不可读的超现实对象 |
| R13 首轮复用 | 字多，文字与配图搭配不合理、不美观 | 长标题三行等权大字 |

## 跨批次避坑（强对照得出）

- 科技感不能只靠蓝紫霓虹；必须有强主体或强排版。
- 抽象技术元素要形成一个容易识别的整体轮廓；零散方块、普通装置、无焦点面板通过率低。
- 浅色不等于好看：打印机、透明抽屉、巨型书页等直译隐喻已整批淘汰。
- 复杂组织场景（办公桌网格、后台剧场、传送带、楼层切面）不如一个强实体。
- 只画出“四个东西”不够，必须与结果形成承重因果（FDE 四笔账：深色四系统、瑞士支柱、色带、算盘、钥匙、锚栓均淘汰）。
- 静态分屏和规整模块陈列通过率低；环抱、核心、对角呼应更稳（中置信）。

## 已淘汰的同构方向（不做变体）

芯片剖面、普通控制台、服务器阵列、液态玻璃、折纸、抽屉、机械臂、缓存门户、数据峡谷、X-ray 模块、银色抽象雕塑、科幻地景、极简舞台。完整清单见 [template-space.md](template-space.md) 的淘汰区。

## 批次淘汰的处理规则

- 用户没有逐张原因时，只记批次事实，禁止直接重跑同一 prompt 和构图，不编造失败原因，也不永久否定对应题材、配色或媒介。
- 中性反馈（一般、不好也不坏）不进入正向或负向库。
- 未采用图片保留本地，不提交。
