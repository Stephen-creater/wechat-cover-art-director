# 模板优先路由

## 核心原则

路由解决的是“哪个已通过模板最能承载新标题”，不是“旧案例和新文章是否同题”。内容相关性只负责替换主体隐喻；模板选择优先看标题容量、构图骨架、明暗、媒介和视觉张力。

## 第一步：判断标题容量

- `短标题`：约 6-14 个中文字符，适合超大字、单行或两行、强主体或高留白。
- `中标题`：约 15-28 个字符，适合两至三行、左右分栏、上下分区或中央标题。
- `长标题/中英混排`：超过 28 个字符，或含多个英文术语、符号、括号；优先宽标题区、编辑网格、三行中央块，避免窄竖栏和复杂穿插。

## 第二步：按模板骨架选择

| 新标题需要 | 优先案例 | 可复用的模板骨架 | 不要求题材相似 |
|---|---|---|---|
| 短标题、强冲突、左右两侧 | A01、A04 | 中央分界、左右张力、标题横跨关系轴 | 可用于商业、技术、观点、组织议题 |
| 中长标题、左文右图、产品感 | A02 | 大标题区 + 单一高质感主体 | 可用于指南、实践、方法论、评测 |
| 中标题、单一强物体、上下因果 | A03 | 上下过滤、冷暖聚焦、中央强物体 | 可用于变化、选择、沉淀、因果 |
| 中长标题、多路径与收敛 | A05 | 纵深路径、目标、冷暖双线 | 可用于训练、策略、决策、效率 |
| 长标题、中央电影空间 | A06、A07 | 三行几何中心、环抱式边缘主体、安静标题雾区 | 可用于任何需要宏大技术感的解释型标题 |
| 长标题、明亮编辑排版 | A08、A13 | 大字、纸张肌理、非对称网格、受控色带 | 可用于教程、观点、清单、方法论 |
| 中长标题、单一核心与横向张力 | A09、A11 | 上方或中央标题、中心主体、左右波场 | 可用于核心机制、价值中心、系统原理 |
| 中长标题、动态对角双主体 | A10、A12、A15 | 左下/右上呼应、中央文字区 | 可用于两个阶段、双系统、比较与协作 |
| 中长标题、明亮空间与双向关系 | A14 | 天空留白、两侧建筑或路径、冷暖对照 | 可用于迁移、连接、演进、交付 |
| 短标题、极强字体尺度、少量几何 | A16 | 瑞士网格、超大字、边缘色块、收束焦点 | 可用于本质判断、争议观点、定义型标题 |
| 长标题、真实材质、积累到结果 | A17 | 左文右标本、层理、单一强调点 | 可用于训练、复利、演化、沉淀、分层机制 |
| 长标题、高调摄影、集中与分散 | A18 | 左文右物、棱镜与自然光、宽阔留白 | 可用于拆解、分流、选择、聚焦、对比机制 |
| 短标题、真实接合物、自然暖光 | A19（弱正向） | 左文右物、深浅材料接合、宽留白 | 只作辅助参考；需要表达协作、契合、接口时考虑 |
| 长标题、单一实验物、运动收敛 | A20（弱正向） | 左文右图、摆动残影、最终亮点 | 只作辅助参考；需要表达反复、稳定、收敛时考虑 |
| 中长标题、阈值前后、正文有强视觉例子 | A21（强正向） | 图上文下、同一主体从不可识别到可识别、展览尺度 | 优先直接适配；适合涌现、识别、临界点、从噪声到意义 |
| 长标题、压缩层次、内部世界 | A22（正常通过） | 左文右标本、层理包裹微缩世界、暖白留白 | 正常结构适配；适合知识压缩、层级、内部模型、长期积累 |
| 长标题、输入转化、科学摄影 | A23（弱正向） | 左文右物、透明光学体、输出微缩世界 | 只借一个维度；不优先重复透明方体或相同投影关系 |
| 短标题、极简信息关系 | A24（弱正向） | 瑞士大字、递减柱、细轴和单一大色块 | 只借字体尺度或功能几何；不直接复刻原分布图 |
| 短标题、正文有一个实体隐喻 | A25（强正向） | 左文右物、高调摄影、极端尺度差、单一真实物体 | 优先直接适配其方法；适合杠铃分布、失衡、少数与多数、表象与真实 |
| 短标题、两端极端与中间空白 | A26（弱正向） | 标题压顶、双峰地貌、空谷与细连接 | 只借双峰尺度或地貌氛围，不复刻盐地场景 |

## 第三步：匹配强度

- `直接适配`：标题容量、构图需求、明暗偏好都命中。仅在用户要高效复用时使用，不占用“探索新模板”的名额。
- `借一维`：只借配色、材质或标题位置中的一个，其余原创。
- `新模板`：当前模板库没有相应骨架，进入 [template-space.md](template-space.md) 的待探索区。

标记为“弱正向”的案例不作为默认直接适配对象。只有其标题容量和关系结构明显合适时，才借用一个维度。

## 批量探索规则

1. 至少覆盖短、中、长三类标题，不必整批使用同一文章。
2. 每个候选先写五元组：`版式 / 明暗 / 媒介 / 主体 / 标题容量`。
3. 与正向模板三项以上相同，视为重复成功方向；与负向模板三项以上相同，视为重复失败方向。
4. 探索批次不读取案例完整 prompt，除非只借一个明确维度。
5. 用户筛选后，才把通过候选加入模板路由；淘汰候选只进入负向索引。

## 内容隐喻的地位

正文仍用于保证元素不奇怪，但不限制模板复用。先选成熟模板骨架，再把文章中的动作、关系或冲突替换进主体；不要因为标题写的是 AI，就自动选择蓝紫核心、轨道或面板。
